# CONTEXT: Sprint R.3 - UX/UI Refactor

**Bối cảnh:**
Mục tiêu của Sprint này là dọn dẹp lại giao diện cột điều hướng bên trái (Sidebar). Trước đây, do vội vàng thêm tính năng, Sidebar bị nhồi nhét quá nhiều thông tin (Profile lặp lại) và thiếu CSS phân tầng khiến UI trông không chuyên nghiệp. Việc tinh chỉnh CSS (như margin, padding, border) sẽ giúp người dùng có trải nghiệm thị giác tốt hơn, tập trung hơn vào các Menu điều hướng.
