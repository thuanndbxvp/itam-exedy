# CONTEXT: B6-B9 - Asset & Report Upgrades Bundle

**Người lập:** Tier 1 (Planner)
**Mục tiêu:** Nâng cấp tính năng cho Tài sản (Upload ảnh, Tài sản con), sửa Form Bản quyền và xây dựng Bảng Báo cáo tổng hợp.

## Scope
1. **[B6] Asset image field + upload:** Cho phép up ảnh thiết bị (Dùng Next.js API route lưu file local hoặc Base64 nếu nhanh).
2. **[B7] Assigned Asset:** Cho phép một thiết bị (chuột, phím) được gán vào một thiết bị khác (Laptop) thay vì gán cho người dùng.
3. **[B8] License companyId selector:** Sửa form Bản quyền, thêm dropdown Company.
4. **[B9] Reports page:** Dựng trang Báo cáo `/reports` với các biểu đồ thống kê cơ bản (Tổng tài sản, tỷ lệ hỏng, tỷ lệ phần mềm hết hạn).
